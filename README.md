# Bob Jarvis

Artist and creative technologist working across sound, moving image, interactive systems, and physical computing.


## Music & audiovisual tools

- **[bop 🐤](https://github.com/zealtv/bop)** — Friendly music-making modules for Pure Data Vanilla.
- **[bopOS](https://github.com/zealtv/bopOS)** — Framework for large scale, Raspberry Pi-based spatial audio.
- **[VIZZable](https://github.com/zealtv/VIZZable-2)** — (Quite old) Modular video toolsfor  Ableton Live.
- **[VIZZable 3](https://github.com/zealtv/VIZZable-3)** — An experimental redevelopment of VIZZable.
- **[AXIS](https://github.com/zealtv/AXIS)** — A MIDI instrument built around a USB Guitar Hero controller.
- **[elevon 🛩](https://github.com/zealtv/elevon)** — Tools for structuring nonlinear musical compositions in Pure Data.
- **[packetPunk](https://github.com/zealtv/packetPunk)** — A ESP32-based OSC capture tool.
- **[glra-midi](https://github.com/zealtv/glra-midi)** — Turn the cheap G-LRA K16_N3 macropad into a MIDI controller.
- **[TouchDesigner ISF Parser](https://github.com/zealtv/TouchDesigner-ISF-parser)** — Convert ISF shaders into TouchDesigner GLSL networks.

## Small tools for agents

A family of lightweight, filesystem-based tools for coordinating human and AI work.

- **[nestlings 🪺](https://github.com/zealtv/nestlings)** *Inbox* — Receive, process, and hand off work between agents.
- **[loom 🪡](https://github.com/zealtv/loom)** *Tasks* — Organise and decompose work into threads and stitches.
- **[glean 🔮](https://github.com/zealtv/glean)** *Memory (short)* — Distil experience into small, reusable findings.
- **[lore 🐉](https://github.com/zealtv/lore)** *Memory (Long)* — Preserve complete artifacts and reference material.
- **[groundhog 🦫](https://github.com/zealtv/groundhog)** *Scheduling* — Schedule recurring work using files and directories.
- **[gremlin 👀](https://github.com/zealtv/gremlin)** — An low maintenance claw-like agent built from the tools above.
